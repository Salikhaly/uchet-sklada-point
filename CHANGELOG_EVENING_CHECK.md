# Вечерняя сверка пункта приёмки

Изменения в этой сборке:
- Главный экран переименован в «Вечерняя сверка» и ориентирован на пункт приёмки: приёмка + свой склад + продажи/отгрузки + деньги + вечерняя проверка.
- На одном экране добавлены рабочие кнопки «Приёмка» и «Продажа / отгрузка».
- Добавлен блок кассовой сверки: остаток утром, деньги пришли, деньги ушли, фактический остаток вечером, расчёт и разница.
- Кассовые поля сохраняются локально в браузере по дате (localStorage). Это не отдельный серверный финансовый журнал.
- Добавлена сетка «Закрытие дня» с переходами в приёмку, продажи/отгрузку, остатки, журнал, отчёты и контроль.
- На главном экране отдельно показывается автоприход и сигнал, что его связь с продажей нужно проверить.
- Заголовок приложения теперь прямо обозначает «Учёт пункта приёмки».

Важно: полноценная серверная фиксация кассы пока не добавлялась, чтобы не ломать текущую схему Supabase. Для неё нужен отдельный финансовый/кассовый слой с открытием/закрытием смены и audit trail.

Проверка сборки: зависимости npm в рабочем окружении не установились (npm install завершился по таймауту), поэтому полный `next build` здесь подтвердить не удалось. Сам исходник проверен статически; существующие ошибки `tsc` связаны в основном с отсутствующими node_modules.
