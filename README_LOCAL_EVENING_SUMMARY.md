# V13 — единый Ангар + вечерняя сводка точки (локально)

Это продолжение V13. Отдельной вкладки «Пункт приёмки» здесь нет.

В существующий склад добавлена только новая вкладка **«Вечерняя сводка»**. Она нужна владельцу для вечернего внесения и сверки данных точки:

- приём за день по товарам;
- отгрузка в Ангар как внутреннее движение с общей себестоимостью;
- прямые продажи клиентам с COGS и валовой;
- деньги: наличные / Kaspi / переводы;
- расходы;
- сотрудники: зарплата / аванс / долг / погашение / выплачено;
- фактический остаток каждого товара и расхождение;
- закрытие дня с комментарием.

Все новые данные пока сохраняются **локально в браузере (localStorage)**. Supabase и Vercel не меняются.

Ангарские вкладки, карточки, отчёты, журнал и существующая модель данных не переписываются.

Запуск:

```cmd
npm install
npm run dev
```
