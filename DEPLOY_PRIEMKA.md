# Деплой Пункта приёмки

## 1. Supabase

Создайте отдельный Supabase project, например `uchet-priemka`.

В SQL Editor или через Supabase CLI примените миграции по порядку из:

`supabase/migrations/`

После этого проверьте RLS и RPC.

## 2. Environment

Создайте `.env.local` на основе `.env.example`.

Минимально нужны переменные Supabase, используемые файлами `lib/supabase/*`, а также серверные секреты, если они предусмотрены текущей схемой авторизации.

**Не используйте URL/ключи Ангара.**

## 3. Проверка

```bash
npm install
npm run typecheck
npm run build
```

## 4. Vercel

Подключите этот проект как отдельный repository/project и выставьте отдельный domain.

## 5. Первый тест

После входа проверить:

- создать товар;
- создать контрагента;
- сделать приход;
- проверить остаток;
- сделать отгрузку;
- открыть журнал;
- открыть отчёт;
- открыть «Контроль»;
- открыть «Вечерняя сводка».

Данные этого контура не должны появляться в Ангаре.
