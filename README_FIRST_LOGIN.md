# Первый вход в локальную сборку

1. Убедись, что в `.env` задан `SUPABASE_SECRET_KEY` (server-only key проекта Supabase).
2. Запусти `npm run dev`.
3. Открой `http://localhost:3000/login`.
4. Введи логин `Ansar` и придумай пароль минимум 6 символов.
5. При первом входе система автоматически создаст auth-пользователя, профиль и рабочий склад «Метал · Ангар».
6. После входа откроется родительский выбор `АНГАР | ТОЧКА`.

Если пользователь `ansar@warehouse.local` уже существует, система не создаёт дубликат и вместо этого восстанавливает профиль, если он отсутствует.
