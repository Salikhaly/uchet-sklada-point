# V13 — вечерний отчёт V3 (локально)

## Что проверено и улучшено

1. Вечерний отчёт разбит на 7 понятных шагов: приём, отгрузки, переработка, деньги, сотрудники, остатки, закрытие.
2. На мониторе появился блок «Вечерний отчёт» с ключевыми цифрами текущей даты и прямым переходом в отчёт.
3. В журнале при выборе одного дня появляется «Отчёт за 1 день»: приход, отгрузка, COGS, валовая и статус вечернего отчёта.
4. В журнале дополнительно показываются данные вечерней сводки за выбранный день, если она уже сохранена локально.
5. Существующие карточки/отчёты/остатки/контрагенты/журнал Ангара не переписываются; изменения добавочные.
6. Закрытие дня сохраняет локальную сводку и требует фактический остаток по активным товарам и объяснение при расхождении.

## Аудиторские правила

- Внутреннее движение «В Ангар» не считается выручкой и валовой прибылью.
- Прямая продажа с пункта считается как выручка − введённый COGS.
- Остаток товара считается: начало + приём + результат переработки − сырьё переработки − в Ангар − прямые продажи.
- Расхождения считаются отдельно по каждому товару и отдельно по каждому денежному каналу.

## Локальность

V3 ничего не пушит в Supabase и не меняет Vercel. Вечерний отчёт хранится в localStorage браузера.
