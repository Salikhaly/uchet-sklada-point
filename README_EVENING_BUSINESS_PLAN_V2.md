# V13 — вечерний учёт точки приёмки внутри единого Ангара

## Что фиксируем

Пункт приёмки не является отдельным приложением и не имеет отдельного каталога товаров. Используется тот же товарный справочник, что и Ангар. Новые данные пока локальные (`localStorage`), Supabase/Vercel не меняются.

## Вечерний сценарий владельца

1. Выбрать дату.
2. По каждому товару внести общий итог приёма за день: число приёмок, кг, сумма. Средняя цена считается автоматически.
3. Указать начальный остаток/стоимость, если это первый день учёта или требуется зафиксировать фактический старт.
4. Внести реальные отгрузки:
   - `В Ангар`: кг + общая себестоимость; в выручку и валовую не попадает.
   - `Клиенту`: кому, товар, кг, сумма продажи, COGS и каналы оплаты. Валовая = продажа - COGS.
5. Если была переработка: сырьё списывается, результат добавляется на склад, отдельно указывается стоимость результата и оплата сотруднику.
6. Ввести деньги: поступления от приёмки, оплаты прямых продаж, погашения долгов, прочие поступления, начальные остатки и фактические остатки по каналам `наличные / Kaspi / перевод`.
7. Ввести расходы и выплаты сотрудникам. Начисленная зарплата не уменьшает кассу; фактически выплаченные зарплата/аванс/долг уменьшают выбранный денежный канал. Возврат долга сотрудником увеличивает канал.
8. Ввести фактический остаток кг по товарам. Расчётный остаток = начало + приём + результат переработки - списание сырья - отгрузки в Ангар - прямые продажи.
9. Если есть расхождения, обязательна причина. День можно закрыть только после исправления жёстких ошибок и пояснения по расхождениям.

## Контрольные правила

- Оплата за приёмку не может превышать сумму принятого товара.
- Оплаты прямых продаж не могут превышать выручку.
- Отрицательный расчётный остаток блокирует закрытие.
- Для активных товаров должен быть введён фактический остаток.
- По каждому товару расхождение считается отдельно; разные товары не взаимозачитываются.
- Внутренние отгрузки `В Ангар` не дают выручки/валовой прибыли.
- Себестоимость внутренней отгрузки фиксируется общей суммой и показывается как ₸/кг.

## Экономика

Стоимость расчётного остатка = начальная стоимость + стоимость принятого + стоимость результата переработки - себестоимость сырья переработки - себестоимость отгрузок в Ангар - COGS прямых продаж.

Средняя себестоимость остатка = стоимость расчётного остатка / расчётный остаток кг.

Прямые продажи: валовая = выручка - COGS.

Переработка: результат = стоимость результата - себестоимость сырья - оплата работы сотрудника.

## Что остаётся неизменным

Ангарские карточки, отчёты, журнал, остатки, монитор и существующая Supabase-логика не переписываются. Эта версия только усиливает локальную вечернюю сводку.
