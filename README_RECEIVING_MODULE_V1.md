# Пункт приёмки V1

Добавлен отдельный модуль «Пункт» в существующий проект склада.

## Что сделано
- отдельный склад пункта приёмки со своей средней себестоимостью;
- приёмка без обязательного контрагента (физлицо/сдатчик/контрагент/сотрудник/другое);
- отдельная кнопка «Склад пункта»;
- статусы товара: «Грузить», «Пока не грузить», «Проверить»;
- прямая отгрузка с пункта без участия Ангара;
- перемещение Пункт → Ангар с переносом текущей средней себестоимости;
- кассовый журнал: наличные, Kaspi, перевод, приход/расход;
- базовый раздел сотрудников;
- вечернее закрытие дня с ожидаемым и фактическим остатком денег;
- отдельные таблицы Supabase и RLS для модуля.

## Важно по Ангару
Карточки, отчёты, монитор, остатки и существующая UI-логика Ангара не переписывались.
Для интеграции перемещения используется существующий движок операций как внутренний приход с заметкой «Перемещение из Пункта приёмки». Финансовый отчёт исключает такие движения из закупочного прихода.

## Миграция
```text
supabase/migrations/202608290010_receiving_point.sql
```

На текущую базу данные не сбрасывать. Использовать:

```powershell
npx supabase db push
npm install
npm run build
npm run dev
```

После успешной сборки — обычный `git add/commit/push`, после чего Vercel подхватит новую версию.
