# V6 — Бумажная схема вечерней записи Точки

Главное окно Точки переделано под фактический вечерний процесс:

1. Один экран с итогами по каждому товару: ОБЩИЙ кг, ОБЩАЯ СУММА, УШЛО кг и расчётный остаток по вечерней записи.
2. Итоги сохраняются в отдельную таблицу `point_evening_product_totals`.
3. Расходы остаются отдельными строками: кому, за что, сумма.
4. Продажи показываются отдельным блоком. Для случайного покупателя контрагент не требуется.
5. Касса — отдельный блок: было утром, принесли за день, расходы, фактический вечерний пересчёт и расхождение.
6. Дополнительные разделы открываются кнопками только при необходимости.
7. Ангарская часть проекта не затрагивается.

Новая миграция:
`supabase/migrations/202608310015_point_evening_product_totals.sql`
