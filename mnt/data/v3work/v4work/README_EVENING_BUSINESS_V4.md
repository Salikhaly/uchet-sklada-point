# V13 Evening Business V4 (local only)

Этот пакет продолжает единый V13 интерфейс. Supabase/Vercel не изменяются.

## Исправлено по аудиту
- остаток по товару теперь учитывает вход/выход переработки;
- фактический остаток проверяется по каждому товару отдельно;
- новый день автоматически переносит начальный кг/стоимость и фактические денежные остатки из последнего закрытого дня;
- долги по приёмке и долги клиентов ведутся отдельным списком и сверяются с расчётным остатком;
- прямые продажи и отгрузка в Ангар проверяют остаток до добавления;
- COGS прямой продажи/отгрузки в Ангар подставляется от текущей средней себестоимости, если не задан вручную;
- переработка не позволяет списать больше доступного сырья и требует стоимости полученного результата;
- журнал за один день показывает вечерний приём, отгрузку в Ангар, прямые продажи, фактические деньги и статус закрытия;
- монитор показывает факт денежных остатков вместе с вечерним отчётом;
- добавлены мобильные/desktop стили для долгов и расширенной вечерней сводки.

## Запуск

В постоянном root проекта:

```cmd
npm install
npm run dev
```

Проверить production-сборку локально:

```cmd
npm run build
```

Никаких миграций, `supabase db push` и Vercel deploy для этой версии не требуется.
