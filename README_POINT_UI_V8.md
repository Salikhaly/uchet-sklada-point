# Точка UI v8 — единое вечернее окно

В этой версии интерфейс Точки перестроен в один рабочий экран в стиле Ангара.

Основной сценарий:
1. Рабочая дата сверху.
2. Быстрые операции: закуп из тетради / отгрузка / продажа / перемещение в Ангар.
3. Склад и остатки видны в том же окне.
4. Вечерняя сводка: куплено, отгружено, продажи, перемещения, касса.
5. Расходы сотрудников: сотрудник → категория → комментарий → сумма.
6. История дня и audit без перехода на отдельные страницы.
7. Проверка дня и закрытие дня в той же сводке.

Существующий Ангар не изменяется.
