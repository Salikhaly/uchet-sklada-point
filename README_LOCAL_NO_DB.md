# Локальная версия без базы

Эта версия намеренно НЕ использует Supabase, Postgres, Docker, RPC, API auth или миграции.

Запуск:

```powershell
npm install
npm run dev
```

Открыть http://localhost:3000

Данные хранятся только в localStorage браузера под ключом `uchet-metalla-local-v11`.

Режимы:
- АНГАР — локальная копия режима для теста.
- ТОЧКА — бумажная схема вечерней сверки.

В Точке доступны:
- общий итог по каждому товару;
- расходы по кому/за что/сколько;
- продажа без контрагента;
- средняя себестоимость продаж;
- касса и расхождение;
- журнал;
- отчёт «кто сколько взял»;
- перемещение Точка → Ангар по средней себестоимости.

После утверждения интерфейса эту модель можно перенести обратно в существующую Supabase-схему.
