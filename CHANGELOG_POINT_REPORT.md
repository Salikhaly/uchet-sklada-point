# Изменения пункта приёмки

- Сохранён режим **«Вечерняя сверка»**: это ежедневное закрытие дня, а не ревизия.
- Ангарная логика и существующие разделы базы сохранены.
- Вечернее окно показывает приёмку, продажи/отгрузки, автоприходы, кассовые поля и кнопку перехода к расшифровкам.
- В отчёте добавлен блок **«Кто сколько взял»**: по каждому контрагенту за выбранный период — кг отгрузки, сумма отгрузки, себестоимость и валовая прибыль.
- В SQL добавлена миграция с `out_kg` для контрагентов, чтобы отчёт показывал именно количество кг, а не только деньги.
- Отменённые операции в отчёт не попадают; автоприход не считается обычной закупкой.
