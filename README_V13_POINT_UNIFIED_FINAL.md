# V13 — Единый локальный пункт приёмки

Это локальная версия проекта на основе V13. Название «Ангар» как рабочего режима убрано: система используется как пункт приёмки. Сохраняются привычные функции складского учёта — монитор, операция, журнал, остатки, отчёты, карточки, поиск, товары, контроль — плюс вечерний отчёт владельца.

## Логика
- Приём за день по каждому товару: количество приёмок, кг, сумма и средняя цена.
- Отгрузка имеет два назначения: «В Ангар» (внутреннее движение, не продажа) или «Клиенту» (выручка, COGS, валовая).
- Переработка учитывает сырьё, результат, потери и оплату работы.
- Склад пункта считается как начало + приём + результат переработки - сырьё переработки - отгрузка в Ангар - прямые продажи.
- Вечерний отчёт содержит деньги, расходы, сотрудников, долги, фактический остаток и закрытие дня.
- При закрытии сохраняются локальные money/employee ledgers.
- В журнале при выборе одного дня отображается вечерняя сводка этого дня.

## Локальный режим
Supabase и Vercel не изменяются этой версией. Для запуска нужны обычные зависимости проекта и текущий локальный `.env` V13.
