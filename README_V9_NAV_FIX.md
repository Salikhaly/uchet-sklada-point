V9.1 — закрытие карточки при переходе в журнал

Исправлен UX-баг: при клике на накладную/операцию внутри карточки товара, клиента или группы карточка раньше оставалась поверх журнала.

Теперь focusJournalOperation():
- закрывает активную карточку (setModal(null));
- переводит на Журнал;
- раскрывает нужную накладную;
- сохраняет подсветку товара;
- прокручивает нужную накладную в центр после перехода.

Supabase migration не требуется.
