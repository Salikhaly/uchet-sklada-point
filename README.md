# Учёт склада — V2 Supabase + Vercel

Новая версия сделана визуально и функционально близкой к привычному Google Sheets/Apps Script складу, но с PostgreSQL/Supabase как источником правды и Next.js/Vercel как веб-приложением.

## Что есть

- Приход / Отгрузка в плотной табличной форме;
- цены по умолчанию + галочка «Стереть цены»;
- ввод Кг → Сумма без скачков количества: цена считается как Сумма / Кг;
- счётчик заполненных товаров и итог операции;
- серверная защита от будущей даты и отгрузки в минус;
- новые автоприходы отключены;
- повтор операции;
- журнал с редактированием, историей и отменой вместо физического удаления;
- восстановление отменённой операции;
- версии операций и idempotency key;
- история изменений «было/стало» на уровне БД;
- группы контрагентов, включая Димаш → мини-контрагенты;
- товары + история цен;
- остатки + средневзвешенная себестоимость;
- прибыль, COGS, маржа по товарам и клиентам;
- контроль склада через RPC;
- черновик сегодняшней операции в localStorage;
- RLS + server-side Supabase SSR.

## Важно

Не запускайте новую миграцию на production, пока не сверены остатки старой Google Sheets-версии и Supabase. Это dev/pre-prod этап.

## После изменения SQL

```bash
npx supabase db push
npm run typecheck
npm run build
npm run dev
```
