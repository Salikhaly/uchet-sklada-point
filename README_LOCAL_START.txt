ПУНКТ ПРИЁМКИ — LOCAL BUILD

Это локальная версия. Supabase и Vercel для запуска НЕ НУЖНЫ.
Данные сохраняются в localStorage браузера на этом компьютере.

Запуск Windows:
1. Установить Node.js LTS.
2. Открыть PowerShell в этой папке.
3. npm install
4. npm run dev
5. Открыть http://localhost:3000

Важно:
- Не удаляйте данные браузера/Local Storage, пока работаете с тестовыми данными.
- Это тестовая локальная база, отдельная от Ангара и Supabase.
- Сначала проверяем сценарий пункта и вечернюю сверку локально.
