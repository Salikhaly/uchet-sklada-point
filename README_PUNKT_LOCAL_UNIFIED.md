# Пункт приёмки — единый локальный режим V13

Это локальная надстройка внутри существующего V13. Ангарская логика не переписывается.

## Принцип
- Один общий каталог товаров из Ангара.
- Пункт приёмки — отдельная локация/склад внутри интерфейса.
- Контрагенты для пункта не обязательны и отдельного каталога контрагентов нет.
- Есть только два типа операций: `ARRIVAL` и `SHIPMENT`.
- Отгрузка имеет назначение: `CLIENT` или `ANGAR`.
- Отгрузка в Ангар НЕ является отдельным типом перемещения и не учитывается как выручка.
- Для отгрузки в Ангар учитывается только кг и общая себестоимость (по умолчанию из средней себестоимости пункта).
- Для прямой отгрузки клиенту учитываются продажная сумма, COGS и валовая прибыль.
- Вечерний отчёт объединяет товар, деньги, расходы и сотрудников в одной форме.
- Данные этого локального модуля хранятся только в localStorage. Supabase/Vercel не меняются.

## Проверка
- `components/receiving-local.tsx` проходит TSX transpile.
- `components/warehouse-app.tsx` проходит TSX transpile.
- Бизнес-логика сохранения Ангара не изменяется.
