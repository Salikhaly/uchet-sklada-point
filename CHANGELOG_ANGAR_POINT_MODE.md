# ANGAR / ТОЧКА — режимы работы

## Что сделано
- Ангар восстановлен отдельным приложением из исходной v13-системы.
- Точка вынесена в отдельное приложение с вечерней сверкой, расходами, продажами без контрагента и отчетом по контрагентам.
- Входная страница теперь выбирает родительский режим: **Ангар** или **Точка**.
- Для Точки создан отдельный workspace, который создаётся один раз при первом входе и дальше используется постоянно.
- Каталог товаров и контрагенты клонируются из Ангара в Точку при первичном создании, но операции и остатки не смешиваются.
- Ангарские операции и остатки остаются в исходном workspace без миграции/переноса.
- Кнопка переключения между режимами есть внутри обоих интерфейсов.

## База
Миграция: `supabase/migrations/202608310013_angar_point_modes.sql`

Она добавляет:
- `profiles.point_workspace_id`
- `profiles.active_mode`
- `current_workspace_id()` с учётом активного режима
- `switch_app_mode('ANGAR'|'POINT')`
- корректную RLS-политику профиля при переключении

## Важно
При первом входе в «Точку» данные Ангара не переносятся: создаётся отдельное рабочее пространство с копией справочников. Склад Точки начинается со своих остатков и своих операций.
