# V15 — локальная версия Пункта приёмки

Это отдельная dev-ветка для Пункта приёмки. **Ангар не переписывается и его текущая логика не меняется.**

## Что добавлено
- отдельный склад Пункта приёмки;
- приёмка от физлица/сдатчика/контрагента/сотрудника;
- распределение денег при приёмке: CASH / KASPI / TRANSFER / DEBT;
- прямая отгрузка с Пункта с распределением оплаты и COGS;
- перемещение Пункт → Ангар с сохранением средней себестоимости;
- статусы Грузить / Пока не грузить / Проверить;
- касса;
- долги контрагентов;
- зарплаты/авансы/долги сотрудников;
- закрытие дня с отдельной сверкой CASH/KASPI/TRANSFER;
- переработка: сырьё → результат, стоимость результата, выплата сотруднику, расчёт оценочного результата.

## ВАЖНО: пока только локально
Не пушить V15 в текущий production/Vercel Ангара.
Не делать `supabase db reset` на рабочей базе Ангара.
Эту ветку лучше использовать с отдельным dev Supabase проектом.

## Миграции
Новая dev-миграция:
- `202608290011_receiving_finance_complete.sql`
- `202608290012_receiving_processing.sql`

В V15 исправлен дефект `next_receiving_number()` в миграции 011 для чистого развёртывания на новой dev-базе.

## Запуск
```powershell
npm install
npm run dev
```

Если подключаешь отдельный dev Supabase:
```powershell
npx supabase db push
npm run dev
```

## Что остаётся неизменным
Модуль Ангар (`operation`, `journal`, `stock`, `report`, `clients`, `products`, карточки, существующие отчёты) не менялся бизнес-логически.
